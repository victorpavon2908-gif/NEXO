# NEXO

NEXO es una app Android de citas centrada en conexiones reales, privacidad y comunicación directa.

## Visión

Construir una alternativa ligera a las apps de citas tradicionales, con menos datos centralizados y una experiencia enfocada en autenticidad, control de privacidad y comunicación segura.

## MVP 0.1

- Onboarding y acceso inicial
- Creación de perfil
- Descubrimiento de personas
- Like / pasar
- Match mutuo
- Lista de matches
- Chat local de demostración
- Base preparada para Supabase, cifrado E2E y WebRTC P2P

## Tecnología

- Android nativo
- Kotlin
- Jetpack Compose + Material 3
- Arquitectura por capas sencilla
- Supabase/PostgreSQL (siguiente fase)
- Firebase Cloud Messaging (siguiente fase)
- WebRTC para voz/video P2P (siguiente fase)
